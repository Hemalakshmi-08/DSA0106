Topic: Exception Handling Mechanism, Catch Handler Ordering
Problem Statement
A banking software application defines a hierarchy of custom exceptions. A developer writes a try-catch block to handle withdrawals, but the specific derived exception handler for overdrafts is never reached because the base exception handler shadows it.

3. State the rule for ordering exception handlers in C++ when dealing with inheritance hierarchies.
